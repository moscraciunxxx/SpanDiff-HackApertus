# SpanDiff data flow

Development documents only.

1. Encode each side locally with a forward pass of `swiss-ai/Apertus-v1.5-8B`. Do not call an endpoint. Do not generate text.
2. Read hidden state 15 (`hidden_states[15]`; index 0 is the embedding). Index 32, after the final norm, is the final-layer baseline. Hidden state 8 is the ablation.
3. Mean-pool subwords into whitespace tokens. A subword goes to the token it overlaps most. An equal overlap stays on the earlier token. An empty offset, such as the leading special token, is not pooled. A token with no subword is a zero vector and scores 1. Encoded untokenized text leaves 6788 of 405654 development tokens empty. Each is one character and the graded file scores it at 1. Space-joined text leaves none empty, and that string is not encoded.
4. Encode in windows of at most 512 tokenizer tokens, including special tokens. The development set is 1619 such windows, and none is longer than 512. Those windows are 564349 tokenizer tokens. Each of those windows has only the leading beginning-of-sequence token, and it is not pooled. Stitch those windows, then take the max cosine over the other side's full sequence.
5. Score = clamp(1 - that cosine, 0, 1), rounded to 6 decimals before it is written. The paper's DiffAlign uses the final hidden state, index 32 after the final norm, and does not clamp.
6. Write encoder JSON: `id`, `text_a`, `text_b`, `labels_a`, `labels_b`.
7. Grade only with the development command in the README. A clone without the evaluator checkout fetches the development gold and the grader and does not load the model. The published scripts init imports a helper that itself imports an API client, so the init is blanked before the grade even when that helper file is present. A prediction file that is present but not the 168-line set is refused before Docker, does not load the model, and is not continued. With the three 168-line files present, the command does not start Docker when a local interpreter can import the evaluator. If none can and Docker is on PATH, the image grades those files and does not load the model. The image pins CPU torch 2.13.0, numpy 2.3.5, scipy 1.16.3, and tokenizers 0.22.2. It was not run on this machine. That command does not pass `--short`, `--show-std`, or `--split-annotators`. `--short` asks for a gold file this tree does not contain. The default path prints Spearman and Kendall's Tau-b with decimal commas and no ±. `--show-std` prints one bootstrap resample, not a standard deviation. The graded command does not pass it. The annotator flag prints a different table and keeps the decimal point. Before that command, the local check requires 168 lines, the gold id, both texts, and only the encoder keys. Gold is read from the evaluator checkout. Prediction files stay in this repository when that checkout is somewhere else. Every label must be in 0..1 and match the whitespace-token count. It refuses a file that is byte-identical to the last-layer backup. The official script then pairs by file order. On the default path, a short list is padded with 0.0 only when the prefix contains Zurich; otherwise that list plus a tuple of 0.0 raises. A long list is cut, and on side a that cut prints the text. The graded prefix does not contain Zurich, and the lengths already match, so none of those paths ran. list_to_drop.txt lists 33 ids, 15 in these files. Dropping those 15 would print 0,246; 0,164; 0,283, mean 0.2310. The graded prefix does not apply that file. Gold -1 tokens are dropped from the Spearman. 53712 of those positions still have a prediction in 0..1. Those positions and the 351942 kept tokens are the 405654 whitespace tokens. If every gold label on side b is -1, that side is skipped. No development page is in that case.

The studies around this flow are part of the project. The last-block comparison says why step 2 is not the final block: that block lifts aligned tokens and different tokens together. On all 504 development documents, the average-rank pass is higher at layer 15 than at hidden state 8 (mean 0.271 against 0.233). German and Italian peak at layer 14 on that map. The official print for the submitted files is mean 0.270. The graded files are hidden state 15. The three language files share the same English pages in the same order, 65320 whitespace tokens, of which 8431 labels are dropped and 56889 are scored. The drop positions match. On those scored English tokens, all three gold labels are the same 74.4 percent of the time. Of the disagreements, 42 percent have a spread of at least 0.8. On disagreements of at least 0.8, gold at or above 0.8 scores 0.025, 0.012, and 0.044 above gold 0. On all scored English tokens, German scores correlate 0.221 with Italian gold and 0.113 with French gold. Where German and Italian agree and French differs, 3869 tokens, those German scores correlate 0.344 with the agreement and -0.178 with the French label. Among tokens with gold above 0, French Spearman is 0.225 and 0.251, above German at 0.131 and 0.155. Matching Italian's zero-to-positive ratio lifts French from 0.157 to 0.205 and from 0.167 to 0.217, still below Italian at 0.268 and 0.289. Pooling comparisons do not put another pooling into the graded files. On the full development pass, clamped last-subword and clamped subword-then-mean scored higher than clamped mean-pool, and the graded files stay mean-pool. Rare-difference precision, the English-versus-translation split, and the two German annotators say what the score is measuring. In the body, after the first 30 tokens, the German and French 0.8 dip is carried by strings that also appear on the other side: shared strings at gold 0.8 score 0.101 against 0.136 at gold 0.6 in German, and 0.077 against 0.121 in French. Gold-0.8 body tokens absent from the other side sit at 0.204 and 0.203. Years, numbers, and units are 60 of 129 of those German tokens, 80 of 120 French, and 74 of 311 Italian. Dropping that subset raises Spearman by 0.002, 0.003, and 0.002. Sentence matching and a 400-pair OPUS map say where document tokens still fail. Those results stay in the report. They are not written into the three graded files.
