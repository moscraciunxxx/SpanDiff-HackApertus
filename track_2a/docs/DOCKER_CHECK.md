# Windows Docker Desktop verification (`make run`)

On a Windows PC with Docker Desktop running (Linux containers mode), open **WSL2 Ubuntu** or **Git Bash** (where `bash` and `make` are on `PATH`, or run the two `docker` commands directly in PowerShell) and clone with LF line endings preserved so the Linux container shell scripts execute cleanly: `git clone -c core.autocrlf=false https://github.com/moscraciunxxx/SpanDiff-HackApertus.git && cd SpanDiff-HackApertus && make run` (or in PowerShell without `make`: `docker build -t spandiff:local -f track_2a/Dockerfile . ; docker run --rm spandiff:local`). The container builds on `python:3.11-slim-bookworm`, installs CPU `torch==2.13.0` and the pinned `swiss-ai/transformers` commit, downloads the official SwissGov-RSD evaluator and development gold over HTTPS on startup, grades `track_2a/predictions/dev/SpanDiff_admin_{de,fr,it}.jsonl.jsonl` with `--split dev` without loading Apertus weights, and prints the official `DEV TEST RESULTS` table (`Spearman` and `Kendall's Tau-b` for `de`, `fr`, `it`) followed by the four-decimal primary score line. For the committed out-of-fold ridge that line is `0.3430` (`0,393` / `0,239` / `0,397`). The container does not refit the ridge.
